دستیار اکسل T321 ـ بسته شروع ساخت داشبورد هوشمند
=================================================

این بسته یک برنامه مستقل آزمایشی است که از صفر ساخته شده، چون سورس نسخه قدیمی T321 در دسترس نیست.
نسخه قبلی شما جایگزین یا دستکاری نشده است. فعلاً این بسته فقط ماژول داشبورد را دارد؛ ابزارهای قبلی مثل ساخت Word، انتخاب ردیف و پشتیبان‌گیری هنوز در آن ادغام نشده‌اند.

قابلیت‌های فعلی
---------------
- باز کردن فایل‌های Excel با پسوند xlsx و xlsm
- انتخاب برگه، ستون عنوان/گروه و ستون عددی
- محاسبه تعداد مقادیر معتبر، مجموع، میانگین، بیشترین و کمترین مقدار
- رتبه‌بندی گروه‌ها با انتخاب «بیشترین مقدار بهتر است» یا «کمترین مقدار بهتر است»
- نمودار مقایسه‌ای ۱۰ گروه برتر/کمتر
- خروجی اکسل جداگانه شامل داشبورد، نمودار و داده‌های منبع؛ فایل اصلی تغییر نمی‌کند
- خروجی PDF قابل چاپ
- فایل نمونه «نمونه_فروش.xlsx» برای آزمایش پس از ساخت برنامه

ساخت فایل اجرایی ویندوز بدون نصب Python روی رایانه مقصد
--------------------------------------------------------
این بسته برای ساخت از طریق GitHub Actions آماده شده است؛ ساخت روی سرور GitHub انجام می‌شود.

۱) وارد GitHub شوید و یک مخزن جدید (Repository) بسازید.
۲) فایل ZIP را در رایانه خود استخراج کنید.
۳) محتویات پوشه T321_Dashboard_Module را در مخزن GitHub بارگذاری کنید؛ پوشه .github هم باید بارگذاری شود.
۴) از زبانه Actions، گردش‌کار «Build T321 Dashboard EXE» را اجرا کنید (Run workflow).
۵) پس از پایان موفق، در همان اجرای workflow بخش Artifacts را باز کنید و T321_Dashboard_Windows را دریافت کنید.
۶) فایل ZIP خروجی را در ویندوز استخراج کنید و T321_Dashboard.exe را اجرا کنید.

توجه: در نسخه‌های مختلف GitHub ممکن است دکمه‌ها کمی متفاوت باشند. اگر بارگذاری با اینترنت کند متوقف شد، همه فایل‌ها را یکجا بارگذاری نکنید؛ می‌توانیم مرحله‌به‌مرحله پیش برویم.

اجرای آزمایشی روی رایانه‌ای که Python دارد
------------------------------------------
در پوشه برنامه:
  python -m pip install -r requirements.txt
  python t321_dashboard.py

محدودیت‌های فعلی
----------------
- این نسخه ماژول مستقل داشبورد است، نه نسخه کامل و ادغام‌شده T321.
- نمایش فارسی PDF به فونت و پشتیبانی از راست‌به‌چپ در ویندوز وابسته است و باید روی رایانه شما آزمایش شود.
- برای حفظ داده‌ها، خروجی همیشه در فایل جدید ذخیره می‌شود.
